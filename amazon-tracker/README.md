# متتبع أسعار امازون مصر

سيرفر بايثون بيتابع روابط منتجات من amazon.eg + تطبيق أندرويد (APK) بيعرض الأسعار والتغيرات، وإشعارات تليجرام.

## ١) تشغيل السيرفر (على لابتوب/كمبيوتر في البيت شغّال على طول)
```bash
cd amazon-tracker/server
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```
- اختياري: `APP_TOKEN=كلمة_سر` قبل الأمر لو عايز تحمي الـ API.
- افتح `http://IP-الجهاز:8000` من المتصفح للتجربة (نفس الواجهة).
- لازم الموبايل والجهاز على نفس الواي فاي. وللوصول من برّه البيت استخدم Tailscale أو Cloudflare Tunnel.
- يفضّل تشغيله من نت البيت مش من سيرفر مؤجر (عنواين السيرفرات بتتحظر أسرع).

## ٢) تنزيل الـ APK
بعد ما GitHub Actions يخلص (تبويب Actions في المستودع)، الـ APK بيظهر في **Releases ← apk-latest ← amazon-tracker.apk**.
نزّله على الموبايل وثبّته (فعّل "التثبيت من مصادر غير معروفة").

## ٣) الإعداد من التطبيق
الإعدادات ← اكتب عنوان السيرفر (مثال `http://192.168.1.10:8000`) ← حفظ.

## ٤) إشعارات تليجرام
1. كلّم @BotFather واعمل بوت جديد، وخد الـ Token.
2. ابعت أي رسالة للبوت، وبعدين افتح `https://api.telegram.org/bot<TOKEN>/getUpdates` وخد `chat.id`.
3. حطهم في الإعدادات ← إرسال إشعار تجريبي.

## ملاحظات
- الفحص الافتراضي كل ١٥ دقيقة بفواصل عشوائية. أقل حد ٣٠ ثانية، لكن كل ما قلّلت زاد خطر الحظر.
- لو امازون حظرت مؤقتاً (كابتشا) السيرفر بيوقف ويكمل لوحده ويبعتلك تنبيه.
- السحب الآلي بيخالف شروط امازون، فاستخدمه لقايمة صغيرة وللاستخدام الشخصي.
